# ZBTips Controller Symptom Checker V1

A free static web app built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` = the page shell
- `style.css` = styling
- `app.js` = symptom logic, routing, results, glossary

## Local run
Open `index.html` in your browser.
